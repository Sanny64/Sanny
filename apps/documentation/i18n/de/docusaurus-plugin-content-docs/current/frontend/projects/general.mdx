## Frontend-Workspaces

Beide Apps verwenden React 19, TypeScript, Vite und die Data-Router-APIs von React Router. In `main.tsx` steht `ThemeProvider` vor `LanguageProvider`; `App.tsx` erstellt jeweils einen `createBrowserRouter`, der mit `RouterProvider` gerendert wird.

Die gemeinsame `AppShell` aus `@sanny/ui` stellt den gebrandeten Rahmen, Skip-Navigation und ein fokussierbares Main-Landmark bereit. Gemeinsame globale und Layout-CSS wird im App-Einstiegspunkt importiert, damit auch eigenständige Routen dieselbe Basis erhalten. Die Party-Routen von Sanny verwenden ein separates Auxiliary-Layout mit routenspezifischen Farben.

Die Routen sind vorhanden, aber die Seiteninhalte von Portfolio, Projekten, Spielen, Blog und Party zeigen derzeit übersetzte Platzhalter. Einstellungen/Admin und die Account-Linking-Abläufe der Auth-App sind interaktiv. Eigenständige Spiele unter `games/` sind von den Sanny-Routen getrennt.
