Clone this repository to access all applications in the workspace. You need Node.js 24, npm 11.6.3, and Git.

## Installation and Setup

Install all workspace dependencies from the repository root:

```sh
npm ci
```

If your globally active Node.js version differs from the repository pin, run npm commands with the pinned Node.js and npm versions through `npx`:

```sh
npx --yes --package=node@24 --package=npm@11.6.3 -- npm ci
npx --yes --package=node@24 --package=npm@11.6.3 -- npm run test:ci
```

Use the same prefix before other `npm` commands.

The root `tsconfig.json` owns strict, environment-neutral defaults and repository tooling checks. Both frontend apps and the source-exported shared packages extend the single browser configuration at `apps/frontend/tsconfig.frontend.json`; frontend environment declarations live in `apps/frontend/frontend-env.d.ts`.

Run each app you need in its own terminal:

- `npm run dev:sanny`
- `npm run dev:auth`
- `npm run dev:docs`
- `npm run dev:docs:de`
- `npm run start:stack`
- `npm run initialize:stack` for the initial backend image build and full development stack startup

Sanny is served at `https://localhost:5173`, Auth at `https://localhost:5174`, and English docs at `http://localhost:3000`. The German docs command serves `http://localhost:3000/de/`; to use a separate port, run `npm run dev:de -w documentation` for `http://localhost:3001/de/`. Frontend development servers use a local HTTPS certificate. Stop the backend stack with `npm run stop:stack` when finished.

## Builds

Run `npm run check` before manual builds; build commands do not run static checks.

- `npm run build:auth`, `npm run build:sanny`, and `npm run build:docs` build individual targets; `build:docs` builds both configured locales. Use `build:docs:en` or `build:docs:de` for a single locale.
- `npm run build:frontend` builds Auth, Sanny, and both documentation locales.
- `npm run build:backend` builds the backend image but does not start services.
- `npm run initialize:stack` rebuilds required images and recreates the full development Compose stack; `npm run restart:backend` recreates only the backend service. Both preserve volumes.

The backend needs local environment configuration and certificates before it can start; see [Backend Setup](../backend/backend-setup.mdx).

## Workspace Map

- `apps/frontend/sanny/`: public React/Vite site and routed pages.
- `apps/frontend/auth/`: account-link confirmation and ownership-proof frontend.
- `apps/backend/`: Fastify API, Auth0 scripts, Prisma schema, Docker Compose, and monitoring configuration.
- `shared/packages/`: `@sanny/i18n`, `@sanny/styles`, and `@sanny/ui`.
- `apps/documentation/`: Docusaurus source in English and German.
- `shared/tests/`: Repository contracts and Playwright end-to-end suites.
- `tooling/scripts/`: Repository-wide runtime, test, release, and documentation scripts.
- `games/`: standalone game projects.
