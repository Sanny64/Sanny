Sanny64 is my personal website and the home of my portfolio, event-planning pages, and smaller entertainment projects. The site brings these interests together while giving visitors a place to explore my work and projects.

This repository contains more than the public website. It is a modular monorepo that also includes an authentication frontend, a backend API, shared frontend packages, and this developer documentation.

## What the Project Includes

- **Public website:** Portfolio, projects, games, blog, and event-related pages.
- **Authentication:** An Auth0-backed account flow for protected actions and services.
- **Backend:** A Fastify API that provides application services and protected user features.
- **Shared frontend packages:** Common language, theme, and UI functionality used by the website and authentication app.
- **Documentation:** Guides and project context for developing and maintaining the site.

The public routes for the portfolio, projects, games, blog, and party pages are present, but their page bodies currently render translated placeholder content. The interactive account, settings, admin, and account-linking flows are separate and are implemented in the frontend and backend.

---

## Project Vision

Sanny64 aims to be an accessible, personal space for exploring my portfolio, projects, games, writing, and event resources. The experience should be mobile-first and user-centered, with intuitive navigation, purposeful micro-interactions, English and German support, and light and dark themes. Authentication and role-based permissions should protect only the actions and information that require them. A modular, resource-conscious architecture should keep product areas clear and avoid unnecessary integrations.

## Shared Focus

The shared packages keep language, theme, settings, and common UI aligned across the public site and Auth instead of reimplementing them in each app. This centralizes maintenance for accessibility, localization, and styling behavior.
