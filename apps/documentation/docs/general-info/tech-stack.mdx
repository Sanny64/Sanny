This workspace is a TypeScript monorepo for the public website, authentication app, backend services, and documentation.

## Frontend

- React 19 and TypeScript, built with Vite
- React Router for client-side routing
- Framer Motion for animations and reduced-motion-aware transitions
- Shared `@sanny/i18n`, `@sanny/styles`, and `@sanny/ui` packages for localization, themes, and UI
- The browser apps call the Fastify API; the backend handles Auth0's authorization-code flow, PKCE, and server-side sessions

---

## Backend

- Fastify 5 and TypeScript provide the REST API
- Prisma ORM accesses the MariaDB database
- Redis stores session and rate-limit state
- Auth0 provides authentication; backend authorization protects user-specific features
- Zod validates API data, and Pino provides structured application logging
- NGINX is the reverse proxy in the Docker Compose environment

---

## Monitoring and Runtime

- Docker Compose runs the backend and supporting services
- Prometheus collects metrics; Grafana provides dashboards and alerting
- Loki and Alloy aggregate application and NGINX logs
- Redis, NGINX, and host exporters expose internal metrics to Prometheus

---

## Authentication

- The `apps/frontend/auth/` workspace provides account-link confirmation, ownership-proof, request-state, and settings routes; it is not a standalone sign-in form
- The backend initiates and completes Auth0 authentication and protects API routes with its session and authorization checks
- Auth0 database and post-login actions support account registration, verification, and identity linking

---

## Documentation and Tooling

- Docusaurus 3 and MDX build the English and German documentation sites
- npm workspaces manage the frontend apps, shared packages, backend, and documentation
- TypeScript, ESLint, Prettier, and Playwright support type checking, linting, formatting, and browser testing
