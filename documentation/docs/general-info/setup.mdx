Clone this repository to get access to all applications in this workspace.<br/>You will need Node.js and Git installed on your machine.

---

### Installation and Setup Instructions

Install dependencies from the repository root:

```sh
npm ci
```

_In the root directory, run one of the workspace scripts:_

- npm run dev:sanny
- npm run dev:auth
- npm run dev:docs
- npm run dev:docs-de
- npm run start:backend

Run each app you need in its own terminal. Sanny is served at `https://localhost:5173`, Auth at `https://localhost:5174`, and the English docs at `http://localhost:3000`. The German docs script uses port `3001`. Frontend development servers use a local HTTPS certificate; the pages reload when their source changes. Stop the backend stack with `npm run stop:backend` when finished.

### Workspace Map

- `sanny/`: public React/Vite site and its routed pages.
- `auth/`: authentication helper UI for confirmation and ownership-proof flows.
- `backend/`: Fastify API, Auth0 scripts, Prisma schema, Docker Compose, and monitoring configuration.
- `shared/packages/`: the `@sanny/i18n`, `@sanny/styles`, and `@sanny/ui` packages.
- `documentation/`: Docusaurus source in English and German.
- `games/`: standalone game projects.
