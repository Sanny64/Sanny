Clone this repository to access all applications in the workspace. You need Node.js 24, npm 11.6.3, and Git.

### Installation and Setup

Install all workspace dependencies from the repository root:

```sh
npm ci
```

Run each app you need in its own terminal:

- `npm run dev:sanny`
- `npm run dev:auth`
- `npm run dev:docs`
- `npm run dev:docs:de`
- `npm run start:backend`
- `npm run restart:stack` for the initial backend image build and full development stack startup

Sanny is served at `https://localhost:5173`, Auth at `https://localhost:5174`, and English docs at `http://localhost:3000`. The German docs command serves `http://localhost:3000/de/`; to use a separate port, run `npm run dev:de -w documentation` for `http://localhost:3001/de/`. Frontend development servers use a local HTTPS certificate. Stop the backend stack with `npm run stop:backend` when finished.

### Quality Checks

- `npm run format:check`
- `npm run check`
- `npm run test:ci`
- `npm run test` for the full gate, including live Auth0 checks

### Builds

Run `npm run check` before manual builds; build commands do not run static checks.

- `npm run build:auth`, `npm run build:sanny`, and `npm run build:docs` build individual targets; `build:docs` builds both configured locales. Use `build:docs:en` or `build:docs:de` for a single locale.
- `npm run build:frontend` builds Auth, Sanny, and both documentation locales.
- `npm run build:backend` builds the backend image but does not start services.
- `npm run restart:stack` rebuilds required images and recreates the full development Compose stack; `npm run restart:backend` recreates only the backend service. Both preserve volumes.

The backend needs local environment configuration and certificates before it can start; see [Backend Setup](../backend/backend-setup.mdx).

### Workspace Map

- `sanny/`: public React/Vite site and routed pages.
- `auth/`: account-link confirmation and ownership-proof frontend.
- `backend/`: Fastify API, Auth0 scripts, Prisma schema, Docker Compose, and monitoring configuration.
- `shared/packages/`: `@sanny/i18n`, `@sanny/styles`, and `@sanny/ui`.
- `documentation/`: Docusaurus source in English and German.
- `games/`: standalone game projects.
