# Auth

Das Auth-Projekt ist das auf Authentifizierung fokussierte Frontend des Monorepos. Es wurde mit React, TypeScript und Vite erstellt und ist dafür gedacht, Sign-in-bezogene Abläufe in einer dedizierten App zu verwalten, anstatt sie mit der öffentlichen Website zu vermischen.

---

## Zweck

- Eine fokussierte Authentifizierungserfahrung bereitstellen
- Geschützte Abläufe von den öffentlichen Portfolio-Seiten trennen
- Sprache, Theme und UI-Verhalten mit dem Rest des Workspaces teilen
- Durch Shared Packages klein und wartbar bleiben

---

## Gemeinsame Abhängigkeiten

Die Auth-App nutzt die gemeinsamen Workspace-Packages, um mit dem Rest des Projekts konsistent zu bleiben:

- `@sanny/i18n` für Sprachverwaltung und Übersetzungen
- `@sanny/styles` für Theme und globalen Styling-Zustand
- `@sanny/ui` für wiederverwendbare Komponenten und gemeinsame UI-Muster

Auth und Sanny verwenden `AppShell`, semantische Farbvariablen fuer helle und dunkle Oberflaechen, lokal eingebundene Manrope-Schrift und Framer-Motion-Vorgaben mit `reducedMotion="user"`. Die gemeinsamen Styles werden in `src/main.tsx` importiert und gelten auch fuer eigenstaendige Fehler- und Proof-Routen.

## Entwicklung und Deployment

Die Befehle im Repository-Stamm sind `npm run dev:auth`, `npm run lint:auth`, `npm run build:auth` und `npm run test:frontend:accessibility:auth`. Die App laeuft unter `https://localhost:5174`.

Der Workflow `deploy-auth.yml` uebergibt den Build als Artefakt und veroeffentlicht `auth/dist/` unter `/public_html/auth/`. Der Document Root der Auth-Subdomain muss darauf zeigen. Backend-Login-Endpunkte und Auth0-Callbacks bleiben unveraendert. Die Startseite zeigt den Anfragestatus und gemeinsame Darstellungseinstellungen, kein separates Login-Formular.
