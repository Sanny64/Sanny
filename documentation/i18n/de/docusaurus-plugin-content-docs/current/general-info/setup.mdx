Klone dieses Repository, um Zugriff auf alle Anwendungen im Workspace zu erhalten. Du benötigst Node.js 24, npm 11.6.3 und Git.

### Installation und Einrichtung

Installiere alle Workspace-Abhängigkeiten im Repository-Stammverzeichnis:

```sh
npm ci
```

Starte jede benötigte App in einem eigenen Terminal:

- `npm run dev:sanny`
- `npm run dev:auth`
- `npm run dev:docs`
- `npm run dev:docs:de`
- `npm run start:backend`
- `npm run restart:stack` für den initialen Image-Build und den vollständigen Entwicklungs-Stack

Sanny läuft unter `https://localhost:5173`, Auth unter `https://localhost:5174` und die englische Dokumentation unter `http://localhost:3000`. Der deutsche Root-Befehl verwendet `http://localhost:3000/de/`; für einen separaten Port starte `npm run dev:de -w documentation`, das `http://localhost:3001/de/` bereitstellt. Frontend-Dev-Server verwenden ein lokales HTTPS-Zertifikat. Beende den Backend-Stack nach der Arbeit mit `npm run stop:backend`.

### Qualitätsprüfungen

- `npm run format:check`
- `npm run check`
- `npm run test:ci`
- `npm run test` für das vollständige Gate einschließlich Live-Auth0-Prüfungen

### Builds

Führe vor manuellen Builds `npm run check` aus; Build-Befehle führen keine statischen Prüfungen aus.

- `npm run build:auth`, `npm run build:sanny` und `npm run build:docs` bauen einzelne Ziele; `build:docs` erstellt beide konfigurierten Sprachen. Für eine einzelne Sprache `build:docs:en` oder `build:docs:de` verwenden.
- `npm run build:frontend` baut Auth, Sanny und beide Dokumentationssprachen.
- `npm run build:backend` baut nur das Backend-Image und startet keine Services.
- `npm run restart:stack` baut benötigte Images und erstellt den gesamten Entwicklungs-Compose-Stack neu; `npm run restart:backend` erstellt nur den Backend-Service neu. Beide erhalten Volumes.

Das Backend benötigt vor dem Start eine lokale Umgebungskonfiguration und Zertifikate; siehe [Backend-Setup](../backend/backend-setup.mdx).

### Workspace-Übersicht

- `sanny/`: öffentliche React-/Vite-Website und ihre gerouteten Seiten.
- `auth/`: Frontend für Account-Link-Bestätigung und Besitznachweis.
- `backend/`: Fastify-API, Auth0-Skripte, Prisma-Schema, Docker Compose und Monitoring-Konfiguration.
- `shared/packages/`: `@sanny/i18n`, `@sanny/styles` und `@sanny/ui`.
- `documentation/`: Docusaurus-Quellen auf Englisch und Deutsch.
- `games/`: eigenständige Spieleprojekte.
