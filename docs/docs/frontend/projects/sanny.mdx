## Special Behavior

The Sanny frontend project uses two layout wrappers (`Main.tsx` and `Auxiliary.tsx`) that share the same layout baseline.

Both wrappers import shared styles:

- `@sanny/styles/globals.css`
- one layout stylesheet (`@sanny/styles/main.css` or `@sanny/styles/auxiliary.css`)

The difference is intentionally color-only for auxiliary routes:

- `auxiliary.css` exposes route-scoped variables for background and text.
- route styles provide values for those variables.

Current auxiliary layout pattern:

```typescript
{/* Example Auxiliary.tsx */}

import { Outlet, useLocation } from 'react-router-dom';
import '@sanny/styles/globals.css';
import '@sanny/styles/auxiliary.css';
import '../styles/auxiliary-page-one.css';    // contains .auxiliary-layout--1
import '../styles/auxiliary-page-two.css';    // contains .auxiliary-layout--2
import '../styles/auxiliary-page-three.css';  // contains .auxiliary-layout--3

export default function Layout() {
  const { pathname } = useLocation();

  function getRouteClass() {
    switch (pathname) {
      case '/auxiliary-page-1':          // set route in web url
        return 'auxiliary-layout--1';    // layout name set in (here) auxiliary-page-one.css
      case '/auxiliary-page-2':
        return 'auxiliary-layout--2';
      case '/auxiliary-page-3':
        return 'auxiliary-layout--3';
      default:
        try {
          console.error('Unknown route:', pathname);
          return '';
        } catch (e) {
          console.error('Error occurred while determining route class:', e);
          return '';
        }
    }
  }

  const routeClass = getRouteClass();

  return (
    <div className={`auxiliary-layout ${routeClass}`}>
      <Outlet />
    </div>
  );
}
```
