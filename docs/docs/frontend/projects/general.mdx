## All frontend projects

... share the same structure:

- ReactJS + TypeScript + Vite
- most configs are extended versions of the root configs
- index.html remains unchanged
- main.tsx -> context provider
- App.tsx -> routing component
- All `{ children }` (sub-pages) are routed through a layout .tsx file, for example Main.tsx, which loads globals.css and main.css:

```typescript
{/* Main.tsx */}
import { Outlet } from 'react-router-dom';
import '@sanny/styles/globals.css';
import '@sanny/styles/main.css';

export default function Layout() {
  return (
    <div className="layout">
      <a href="#main-content" className="skip-link">
        Skip to main content
      </a>
      <main id="main-content" className="main-content">
        <Outlet />
      </main>
    </div>
  );
}
```

This is then used in App.tsx:

```typescript
import { BrowserRouter, Routes, Route } from 'react-router-dom';
import Main from './pages/Main';
import Sample from './pages/sample/Sample';

<BrowserRouter>
  <Route element={<Main />}> // loads globals.css + main.css
    <Route path="*" element={<Sample />} /> // keeps the shared layout baseline in place
  </Route>
</BrowserRouter>
```
