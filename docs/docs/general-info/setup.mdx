Clone this repository to get access to all applications in this workspace.<br/>You will need Node.js and Git installed on your machine.

---

### Installation and Setup Instructions

Installation: npm install

_In the root directory, run one of the workspace scripts:_

- npm run dev:sanny
- npm run dev:login
- npm run dev:docs
- npm run dev:docs-de

Running the dev scripts will open http://localhost:5173 for frontend projects and http://localhost:3000 for docusaurus to view the selected app in dev mode in your browser. The page will reload automatically if you make edits.

_For quality checks:_

- npm run lint
- npm run build
- npm run test (lint & build)
  - will replaced with actual tests soon

_For local builds:_

- npm run build:sanny
- npm run build:login
- npm run build:docs
- npm run serve:docs (builds the docs beforehand)
