# User Data

## Currently
Cookies save language, theme and accessibility settings.

---

## Future use
### User data storage

#### Must haves
- UserId (primary key)
- Username
- Password
#### Optional
- Integrations
    - Email (Gmail integration)
    - Phone (WhatsApp integration)
- if not set, falls back to system-preference
    - theme settings
    - language settings
    - accessibility settings

Not-logged-in users will have their accessibility settings saved in cookies and localStorage, but with limited usage options available.
