Klone dieses Repository, um Zugriff auf alle Anwendungen in diesem Workspace zu erhalten.<br/>Du benötigst Node.js und Git auf deinem Rechner.

---

### Installations- und Setup-Anweisungen

Installation: npm install

_Führe im Root-Verzeichnis eines der Workspace-Skripte aus:_

- npm run dev:sanny
- npm run dev:login
- npm run dev:docs
- npm run dev:docs-de

Beim Ausführen der Dev-Skripte öffnet sich für Frontend-Projekte http://localhost:5173 und für Docusaurus http://localhost:3000, damit du die ausgewählte App im Dev-Modus im Browser ansehen kannst. Die Seite lädt sich automatisch neu, wenn du Änderungen vornimmst.

_Für Qualitätsprüfungen:_

- npm run format:check
- npm run lint
- npm run build
- npm run test

_Für lokale Builds:_

- npm run build:sanny
- npm run build:login
- npm run build:docs
- npm run serve:docs (baut die Docs vorher)
- npm run build:backend ->  baut und startet das backend in Docker Desktop, wenn NODE_ENV auf "development" gesetzt ist. Ansonsten muss zunächst ein VPS eingerichtet werden.
- npm run restart:backend -> baut deine -app erneut. redis und nginx sind von dieser Aktion nicht betroffen. 

Info: Nutze `npm run build:backend` erneut um das Ganze backend neu zu bauen 
    - bei Problemen: backend/docker/ `docker-compose down` und dann `docker-compose up --build`.
