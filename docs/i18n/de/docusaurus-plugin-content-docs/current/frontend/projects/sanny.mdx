## Besonderes Verhalten

Das Sanny-Frontend-Projekt verwendet zwei Layout-Wrapper (`Main.tsx` und `Auxiliary.tsx`), die dieselbe Layout-Basis teilen.

Beide Wrapper importieren gemeinsame Styles:

- `@sanny/styles/globals.css`
- ein Layout-Stylesheet (`@sanny/styles/main.css` oder `@sanny/styles/auxiliary.css`)

Der Unterschied ist bei Auxiliary-Routen bewusst nur farblich:

- `auxiliary.css` stellt route-spezifische Variablen für Hintergrund und Text bereit.
- Die Routen-Styles liefern die Werte für diese Variablen.

Aktuelles Muster für das Auxiliary-Layout:

```typescript
{/* Example Auxiliary.tsx */}

import { Outlet, useLocation } from 'react-router-dom';
import '@sanny/styles/globals.css';
import '@sanny/styles/auxiliary.css';
import '../styles/auxiliary-page-one.css';    // enthält .auxiliary-layout--1
import '../styles/auxiliary-page-two.css';    // enthält .auxiliary-layout--2
import '../styles/auxiliary-page-three.css';  // enthält .auxiliary-layout--3

export default function Layout() {
  const { pathname } = useLocation();

  function getRouteClass() {
    switch (pathname) {
      case '/auxiliary-page-1':          // setzt die Route in der Web-URL
        return 'auxiliary-layout--1';    // Layout-Name aus (hier) auxiliary-page-one.css
      case '/auxiliary-page-2':
        return 'auxiliary-layout--2';
      case '/auxiliary-page-3':
        return 'auxiliary-layout--3';
      default:
        try {
          console.error('Unknown route:', pathname);
          return '';
        } catch (e) {
          console.error('Error occurred while determining route class:', e);
          return '';
        }
    }
  }

  const routeClass = getRouteClass();

  return (
    <div className={`auxiliary-layout ${routeClass}`}>
      <Outlet />
    </div>
  );
}
```
