## Lokale Dienste

| Dienst        | Befehl im Repository-Stammverzeichnis | Lokale URL               |
| ------------- | ------------------------------------- | ------------------------ |
| Backend-Stack | `npm run start:backend`               | `https://localhost:8443` |
| Login-App     | `npm run dev:login`                   | `https://localhost:5174` |
| Sanny-App     | `npm run dev:sanny`                   | `https://localhost:5173` |

Installiere Workspace-Abhängigkeiten einmalig mit `npm ci`. Der Backend-Befehl benötigt Docker Desktop.

## Auth0-Konfiguration

Verwende eine dedizierte Entwicklungsanwendung und Testkonten. Trage im Auth0-Dashboard diese lokalen Callback-URLs ein:

```text
https://localhost:8443/api/v001/auth/callback
https://localhost:5174/
https://localhost:5173/
```

Erlaube für Logout `https://localhost:5173/` und `https://localhost:5174/`. Die CORS-Allowlist muss beide Frontend-Ursprünge enthalten. Die zugehörigen Werte kommen aus dem dokumentierten `DEV_*`-Umgebungskontrakt; übernimm keine Produktionswerte in die Entwicklung.
